# Open questions for Xen Developments Ltd.

Raised while rebuilding the website's copy against the printed brochure
(`Brochure Print-01-03-2026 (small).pdf`). Nothing below has been guessed at
on the live site — each item below is either left as "on request" / omitted,
or shown using the more conservative of two conflicting brochure figures.

1. **Road width, Lakeview Tasmee.** Page 1 says *"SW- 60' wide road"*; both
   floor plans on page 4 are captioned *"40 Feet Wide Road"*. Which is
   correct? The site currently doesn't state a road width to avoid picking
   the wrong one.

2. **Floor area, Lakeview Tasmee.** Page 1 says *"2850 sft area per floor"*;
   the Typical Floor Plan on page 4 is labelled *"TYPE-A (2505 SFT)"*. Is
   2,505 sft the net/carpet area and 2,850 the gross floor plate? The site
   currently shows both figures side by side rather than resolving them.

3. **"15+ Years of Excellence."** No founding year appears in the brochure
   or anywhere else we could find. What year should this be measured from,
   so it stays correct next year and the year after?

4. **"500+ Happy Families."** Is this a real count of families housed
   across the 12 completed buildings, or a rounder marketing figure? Happy
   to keep it as-is, but wanted it on record as unverified against any
   document.

5. **Apartments per floor, Lakeview Tasmee.** The Typical Floor Plan shows
   one Type-A unit per floor (G+8 = 8 apartments), but this isn't stated
   as text anywhere in the brochure. Confirm it's one unit per floor before
   we publish an apartment count.

6. **Production domain.** The brochure and the current site both reference
   `www.XenDevLtd.com` / `xendevltd.com`, but that domain currently returns
   "Domain not connected." Is this still the intended domain for this
   rebuild, or should the site target a different one? (This also affects
   where the Open Graph share-card image resolves — see `index.html`.)

7. **The eight completed projects with no description** (Xen Cassiopea,
   Sarwar, Scorpios, Prima Vera, and Projects 818/994/1026, plus Xen
   Nirvana/Orion/Pegasus/Andromeda) — the brochure only pictures these as
   thumbnails on page 8 with no unit counts, sizes, or completion dates. If
   there's a one-page fact sheet for any of them, send it over and we'll
   write real copy instead of the placeholder "handed-over project" line
   each currently has.
